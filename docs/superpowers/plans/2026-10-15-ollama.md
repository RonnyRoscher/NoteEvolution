# Lokales Sprachmodell (Ollama) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An optional local language model (Ollama) writes topic summaries for book headings and core statements for notes in the background, so that "Wohin damit?" searches topic first, then place, "Relevant" understands sections, and "Genauer prüfen" lets the model decide with a reason. Plus durations with progress bars and a small system monitor.

**Architecture:** The AI project gets an Ollama client (`IChatModel`), a SQLite store for the model's texts and their vectors (`understanding.db`, keyed by content fingerprint), pure planning code (fingerprints, inputs, prompts) and a background worker (one request at a time, pausing). `RelevanceService` takes an optional `IUnderstanding` lookup and becomes two-stage. The UI gets a `LanguageModelRuntime` (settings, connection, pull), the worker per vault in `VaultSession`, settings, header progress and pause, the "Wohin damit?" changes, and a system monitor behind `ISystemMonitor` implemented in the desktop project.

**Tech Stack:** .NET 10, Blazor Hybrid (Photino), `System.Net.Http` + `System.Text.Json` for Ollama's REST API, Microsoft.Data.Sqlite (already used by `VectorCache`), xUnit + bUnit.

**Spec:** `docs/superpowers/specs/2026-10-15-ollama-design.md` (binding, incl. section 11)

## Review Focus

1. Ollama is installed but the model isn't pulled yet, or Ollama stops mid-run: every feature must fall back to today's behavior without errors, and the header must say why (Task 8 test `Session_OllamaGoesAway_FallsBackAndRetriesAfter60s`).
2. A book is edited while a summary request runs: the result belongs to the old fingerprint and must not be stored under the new one; the heading is requeued (Task 5 test `Worker_TextChangedDuringRequest_StoresUnderOldFingerprint_Requeues`).
3. The model answers in a different language, with Markdown, or with a preamble ("Hier ist die Zusammenfassung:"): stored text must be the plain content, trimmed to the limit (Task 4 test `Clean_StripsPreambleAndMarkdown_AndTrims`).
4. Closing the app or switching the vault during a long request must not hang or store anything (Task 5 test `Worker_Disposed_CancelsRunningRequest_StoresNothing`).
5. A heading title that repeats (two "Einleitung" chapters) must not share a summary or a fallback identity (Task 3 test `Identity_SameTitleInTwoChapters_Differs`).
