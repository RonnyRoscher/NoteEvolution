# Bilder als Block – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Images can be inserted as blocks of their own into the book (file dialog and clipboard), the editor shows them with a caption, the PDF prints the caption.

**Architecture:** No new block kind: an image is the Logseq syntax `![caption](../assets/name.png)` in the text of a text block. Core finds and writes the syntax (`BlockImages`), imports files into `<vault>/assets` (`VaultAssets`) and inserts the block (`ManuscriptEditor`). In the editor the syntax is an inline atom `image`, mapped like `sourceCite` (`EditorDocMapper`); the node asks C# for the picture (`LoadImage`, a data URL) and caches it. The PDF already prints images; it gains the caption.

**Tech Stack:** .NET 10, Blazor Hybrid (Photino), TipTap/ProseMirror (`src/NoteEvolution.UI/Editor/js`, tests with `node --test`, bundle with `node build.mjs`), xUnit + bUnit, QuestPDF.

**Spec:** `docs/superpowers/specs/2026-11-11-bilder-design.md`

## Global Constraints

- Formats: PNG, JPEG, GIF, WebP, BMP (extensions `.png .jpg .jpeg .gif .webp .bmp`, case-insensitive). At most 20 MB (20 * 1024 * 1024 bytes).
- Only files inside the vault are ever read for display. Remote paths (`^[A-Za-z][A-Za-z0-9+.-]*://`) are never loaded.
- A block that is only shown must stay byte-identical in the file (the mapper's `md` rule).
- Deleting a block never deletes a file in `assets`.
- UI texts are German, in `src/NoteEvolution.UI/Resources/Strings.resx`; code comments and identifiers English, in the style of the neighbouring code.
- Every command saves the editors first (`ManuscriptCommands.PrepareAsync`), refuses a read-only book or an open conflict, and pushes a `StructureUndo`.
- Build/test (PowerShell): `$env:DOTNET_ROOT="$env:LOCALAPPDATA\Microsoft\dotnet"; $env:PATH="$env:DOTNET_ROOT;$env:PATH"; dotnet test NoteEvolution.slnx`. JS: in `src/NoteEvolution.UI/Editor/js` run `node --test test/` and, after changing `editor.js`, `node build.mjs` (the bundle `wwwroot/js/editor.bundle.js` is checked in).
- Commits end with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`; write commit message files without BOM. Never use bare `git stash`. Work only in the worktree, on branch `bilder`.
- Ruling (spec 4, „app-interne Adresse“): the editor gets pictures as data URLs through the JS interop call `LoadImage` and caches them per path in the script, instead of a custom URL scheme of the desktop host. Why: testable without the host, no dependency on Photino's scheme handling. Cost if wrong: a file replaced outside the app shows its old picture until restart; large pictures cost memory.

## Review Focus

1. A path or caption with `_`, `*` or spaces (`![a_b](../assets/x_y z.png)`) must not be read as emphasis nor escaped on writing: shown, saved, byte-identical.
2. A path that leaves the vault (`../../secret.png`, an absolute path) must not be read.
3. Pasting text (no image in the clipboard) must behave exactly as before.
4. An image next to text in the same block (`Text ![x](y.png) mehr`) keeps its text on both sides.
5. A file name that already exists in `assets` with other content must not be overwritten.

```csharp
namespace NoteEvolution.Core.Books;
/// One image in a text: ![Alt](Path)Suffix, Suffix = Logseq's "{...}" directly after it or "".
public readonly record struct BlockImage(string Alt, string Path, string Suffix, int Start, int Length);
public static partial class BlockImages
{
    public static IReadOnlyList<BlockImage> Find(string text);          // regex: !\[[^\]\n]*\]\([^)\n]*\)(\{[^}\n]*\})?  ; Path trimmed
    public static int LengthAt(string text, int index);                 // length of the image starting exactly at index, else 0
    public static string Format(string alt, string path, string suffix = "");
    public static string CleanCaption(string caption);                  // removes ']' , '\r', '\n'; trims
    public static string WithCaption(string text, int imageIndex, string caption); // n-th image of text gets the cleaned caption; rest unchanged; ArgumentOutOfRangeException for no such image
    public static bool IsRemote(string path);                           // ^[A-Za-z][A-Za-z0-9+.-]*://
}

namespace NoteEvolution.Core.Vaults;
public sealed class AssetRefusedException(string reason) : Exception(reason);   // reason: "format" or "size"
public static class VaultAssets
{
    public const long MaxBytes = 20 * 1024 * 1024;
    public static bool IsImageName(string fileName);                    // by extension, Global Constraints
    public static string MimeOf(string fileName);                       // image/png, image/jpeg, image/gif, image/webp, image/bmp
    /// Copies bytes into <vaultRoot>/assets (created if missing) and returns the Markdown path relative to the
    /// directory of bookFilePath with '/' separators (e.g. "../assets/name.png"). Name: fileName's name with every
    /// char outside [A-Za-z0-9._-] replaced by '-', empty stem -> "bild". Same name + same bytes: reused, nothing
    /// written. Same name + other bytes: "-2", "-3", … before the extension. Throws AssetRefusedException("format")
    /// for another extension, ("size") above MaxBytes or for no bytes.
    public static string Import(string vaultRoot, string bookFilePath, string fileName, byte[] bytes);
    /// The full path of the image file a book's Markdown path names (also percent-encoded, as Logseq writes), or null:
    /// remote, not an image name, not existing, or outside vaultRoot (after Path.GetFullPath).
    public static string? Resolve(string vaultRoot, string bookFilePath, string markdownPath);
}
```
