# Block Status, Adopt Buttons, Calm Relevant List – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every text block and detail gets a status. The status controls how the block looks in the book and whether it goes into the PDF; adopted text starts as "Relevant", and "Bemerkung anfügen" adds a remark. The adopt buttons become four direct buttons. The Relevant list stays frozen while a "Wohin damit?" list is open in it.

**Architecture:**
- **Core:** The status is a Core property of a block (`status::` line, or `#notiz` = Bemerkung). Both `Book` and the editor snapshot carry it.
- **Changing it:** Changes are structure-like commands: a `ManuscriptEditor` operation plus a `PageStructureSnapshot` undo, run by `ManuscriptCommands`.
- **Consumers:** The editor only renders the status (attributes + CSS). The PDF filters by it.
- **Adoption:** `LinkService` writes `status:: relevant` on newly created blocks.

**Tech Stack:** .NET 10, Blazor Hybrid (Photino), TipTap 2.27 (esbuild bundle), QuestPDF, xUnit + bUnit.

**Spec:** `docs/superpowers/specs/2026-10-12-status-design.md`. Read it first; this plan argues from it. It builds on `2026-10-08-manuskript-design.md` and `2026-10-09-bereich-design.md`.

**Interfaces:**
- `ManuscriptCommands.SetStatusAsync(AppState state, BlockStatus status, string undoDescription, ILogger logger) → Task<AdoptMessage?>`. It follows the same order as `RunAsync`:
  1. flush;
  2. check for unsaved text;
  3. check read-only and R26;
  4. check that the element at the cursor (its own key, as for Delete) is a text block or detail;
  5. call `ManuscriptEditor.SetStatus`;
  6. save, with a `StructureUndo` entry;
  7. reveal nothing; the cursor stays.
- `RunAsync` handles `SectionCommand.ToggleRemark` (Remark ↔ Draft; any other status → Remark) and `SectionCommand.AddRemark` (`ManuscriptEditor.AddRemark`, then reveal the new key). `CanRun` is false for both on a heading.
