**Goal:** A print output of the PDF export: free trim size, adjustable bleed, optional crop marks, mirrored margins, justified text with German hyphenation.

**Architecture:** `QuestPdfExporter` keeps its simple path untouched and gains a print path chosen by `PdfOptions.Print`. Geometry lives in a small record (`PrintGeometry`), hyphenation in its own class (`Hyphenator`, Liang patterns, embedded pattern file), body composition is shared and parameterised by a `BodyStyle`. The dialog adds the print settings and remembers them in `UiSettings`.

**Tech Stack:** .NET 10, QuestPDF 2026.9.1, xUnit, PdfPig (tests), bUnit (dialog tests).

## Verified techniques (QuestPDF 2026.9.1, spike of 2026-11-14)

These were tried and work; use them as given.

- **Mirrored margins:** page margin 0;
  `page.Content().PaddingTop(off + top).RotateLayoutCounterclockwise().Decoration(deco => { … })`.
  `deco.Before()` is the page's **left** strip, `deco.After()` the right strip. Each is a `Column` with two items,
  `ShowIf(x => x.PageNumber % 2 == 1).Height(…)` and `ShowIf(x => x.PageNumber % 2 == 0).Height(…)` (odd: left =
  `off + inner`, right = `off + outer`; even: swapped). Content:
  `deco.Content().ExtendHorizontal().AlignRight().RotateLayoutClockwise()` — without `ExtendHorizontal().AlignRight()`
  a partly filled page is pushed to the bottom. `off` is the distance from the sheet edge to the trim edge.
  A `Row` with `ShowIf` items instead breaks the layout; do not use it.
- **Bottom margin and page number:** `page.Footer().Height(off + bottom).Column(…)` with one item per parity,
  `ShowIf(parity).PaddingLeft(…).PaddingRight(…).AlignCenter().Text(t => t.CurrentPageNumber())`; an empty column on
  unnumbered pages. No bottom padding on the content.
- **Blank page before the body:** last item of the table of contents column:
  `ShowIf(x => x.PageNumber % 2 == 1).PageBreak()`. The predicate also stores `x.PageNumber + 1` in a captured
  variable; the footer's `ShowIf` hides the number on that page (QuestPDF runs the layout in two passes).
- **Page count:** `ShowIfContext.TotalPages` is null; track the maximum `x.PageNumber` seen in a `ShowIf` predicate.
- **Crop marks:** `page.Foreground().Svg(size => "<svg …>")` with eight `<line>` elements; format numbers with
  `FormattableString.Invariant`.
- **Hyphenation:** QuestPDF breaks at U+00AD and draws the hyphen only at a line end.

```csharp
namespace NoteEvolution.Pdf.Hyphenation;

internal sealed class Hyphenator
{
    public const char SoftHyphen = '\u00AD';
    /// <summary>The German hyphenator from the embedded patterns, loaded once; null if the resource is missing or unreadable.</summary>
    public static Hyphenator? German { get; }
    /// <summary>Patterns in the tex-hyphen txt form, one per line (".ab3a", "1ba").</summary>
    public static Hyphenator FromPatterns(IEnumerable<string> patterns);
    /// <summary>The text with U+00AD at every allowed break inside its words; everything else unchanged.</summary>
    public string Hyphenate(string text);
}
```

Liang's algorithm: lowercase the word (invariant), wrap it in dots, take the maximum digit of all matching patterns
per position, break at odd values. A word is a maximal run of letters (`char.IsLetter`); a run that touches a digit
or contains U+00AD is skipped, as is a run under 6 letters. Left minimum 2, right minimum 3.

    "Wiederholung" → "Wie|der|ho|lung". If the patterns give a different, still correct German division for one of

/// <summary>All lengths in points. Offset: from the sheet edge to the trim edge (bleed, plus 7 mm with crop marks).</summary>
internal sealed record PrintGeometry(

    float Inner, float Outer, float Top, float Bottom, float BodySize)

    public static PrintGeometry From(PrintLayout layout);   // throws ArgumentOutOfRangeException if !layout.IsValid

}

caption, title and contents sizes are the existing ones times `BodySize / 11`. Text stays left-aligned and
unhyphenated in this task (Task 4). `CropMarks` without bleed is ignored.
